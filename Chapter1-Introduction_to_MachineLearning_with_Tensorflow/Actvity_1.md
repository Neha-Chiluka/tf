# **Activity 1.01: Performing Tensor Addition in TensorFlow**

You work in an institute that has three branches, each with two students and in each branch, they teach three subjects. You are required to sum the tensors to represent the total marks scored by each student across branches.

![](https://github.com/Neha-Chiluka/tf/blob/main/images/1.png?raw=true)
 

The steps you will take are as follows:

1.	Import the TensorFlow library.

2.	Create two scalars to represent the total marks scored in Subject A by all students at Branch X using TensorFlow's Variable class. The first variable will have a value of 70 and the second will have a value of 38.

3.	Create a new variable as the sum of the scalars and print the result.
You should get the following output as  **108**

4.	Create a vector with values [70, 79, 51] and a scalar with the value 95 using TensorFlow's Variable class.

5.	Create a new variable as the sum of the scalar with the vector to represent the marks of Student 1 at Branch X and print the result.
You should get the following output:

**array([165,174,146])**

7.	Create three tensors with a rank of 2 representing the marks of each student, subject, and branch using TensorFlow's Variable class. The first tensor will have the value [[70, 79, 51], [38, 40, 59]], the second will have the value [[90, 28, 64], [62, 98, 48]], and the third will have [[39, 33, 55], [45, 97, 47]].

8.	Create a new variable as the sum of the matrices and print the result:
 
**array([199,140,170])
